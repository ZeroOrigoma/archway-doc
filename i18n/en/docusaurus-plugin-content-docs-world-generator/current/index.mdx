# World Generator Documentation

**Archway World Generator** draws the world Archway imports: terrain, biomes, provinces and a territory hierarchy, exported as 16-bit heightmaps and CSV tables.

## The pipeline

Each stage reads the one before it. You can stop anywhere — a heightmap alone is a valid export — and go back without losing hand-made work.

```
Generate ──▶  Sculpt  ──▶  Subdivide ──▶  Export  ──▶  Archway
 noise         brush       provinces      16-bit PNG   movement II
 seed          stencil     territories    RAW, CSV     "Import"
```

:::info The link with Archway
The files written by movement IV are exactly the ones Archway asks for in [Preparing your first world](/en/archway/import/premier-monde): `T_DefinitionMap`, `DT_Definitions`, the heightmap. That is where the two tools meet.
:::
