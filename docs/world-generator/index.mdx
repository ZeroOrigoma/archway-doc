# Documentation World Generator

**Archway World Generator** dessine le monde qu'Archway importe : terrain, biomes, provinces et hiérarchie de territoires, exportés en heightmaps 16 bits et en tables CSV.

<Sheet>

**Nouveau sur World Generator ?** Suivez les quatre mouvements dans l'ordre. Ils vous mènent d'une fenêtre vide à un jeu de fichiers prêt pour le mouvement II d'Archway.

## Le pipeline

Chaque étape lit la précédente. Vous pouvez vous arrêter n'importe où — une heightmap seule est un export valide — et revenir en arrière sans perdre le travail fait à la main.

```
Générer  ──▶  Sculpter  ──▶  Découper  ──▶  Exporter  ──▶  Archway
 bruit         pinceau       provinces      PNG 16 bits    mouvement II
 graine        stencil       territoires    RAW, CSV       « Importer »
```

:::info Le lien avec Archway
Les fichiers écrits par le mouvement IV sont exactement ceux qu'Archway demande dans [Préparer votre premier monde](/archway/import/premier-monde) : `T_DefinitionMap`, `DT_Definitions`, la heightmap. Les deux outils se rejoignent là.
:::
