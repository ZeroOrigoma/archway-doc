# Raccourcis

La liste complète. Une version courte vit dans l'application, sous **Settings → Shortcuts**.

## Document

| Raccourci | Action |
|---|---|
| `Ctrl` + `S` | Enregistrer. Demande un nom la première fois |
| `Ctrl` + `Z` | Annuler |
| `Ctrl` + `W` | Annuler — la variante commode en AZERTY |
| `Ctrl` + `Y` | Rétablir |

L'annulation est un **historique unique** couvrant les modifications de carte et de hiérarchie. Elle défait la dernière chose que vous avez faite, quel que soit le panneau.

:::info Ces raccourcis se taisent dans un champ de texte
`Ctrl`+`Z` dans un champ de nom de territoire est le réflexe pour « annuler ma faute de frappe ». Il ne doit pas jeter du travail de sculpture à la place.
:::

## La carte

| Entrée | Action |
|---|---|
| **Molette** | Zoom, centré sur le pointeur. Plage 10 % – 5000 % |
| **Clic milieu glissé** | Déplacement |
| **Clic gauche / glissé** | Peindre, ou sélectionner — selon l'outil actif |
| **Clic droit** | Prélever, ou arrêter de peindre |

## Le pinceau

Fonctionnent partout, sans sortir le pointeur de la toile :

| Raccourci | Règle | Plage |
|---|---|---|
| `Ctrl` + molette | Taille du pinceau | Rayon 1,5 – 500 |
| `Alt` + molette | Atténuation — vers le **haut** pour un bord plus doux | 0 – 10 |
| `Ctrl` + `Alt` + molette | Rotation, 5° par cran | 0 – 360° |

Maintenir `Ctrl` ou `Alt` supprime le zoom, pour qu'un réglage de pinceau ne déplace jamais la caméra.

## Les vues

| Entrée | Action |
|---|---|
| **Clic** sur un bouton de vue | Bascule la carte sur cette vue |
| `Ctrl` + **clic** sur un bouton de vue | Épingle cette vue en calque translucide |
| `Ctrl` + **clic** sur la vue épinglée | Retire le calque |

## Navigation au clavier

L'application se pilote entièrement sans souris.

| Raccourci | Action |
|---|---|
| `Tab` | Contrôle suivant |
| `Maj` + `Tab` | Contrôle précédent |
| `Espace` ou `Entrée` | Activer le contrôle — bouton, interrupteur, ouvrir ou fermer un groupe |
| `←` `→` | Déplacer la sélection dans un sélecteur segmenté |
| `Échap` | Fermer une feuille, ou relâcher le focus |

Le focus suit l'ordre dans lequel les contrôles sont dessinés, c'est-à-dire l'ordre où ils apparaissent à l'écran. Le contrôle actif est entouré d'un anneau.

`Échap` ne quitte jamais l'application.

### Dans un champ de texte

| Raccourci | Action |
|---|---|
| `Ctrl` + `A` | Tout sélectionner |
| `Ctrl` + `C` / `X` / `V` | Copier / couper / coller |
| `Maj` + flèches | Étendre la sélection |
| `Origine` / `Fin` | Début / fin du champ |
| `Entrée` | Valider et relâcher le focus |
| `Échap` | Relâcher le focus |
| Double-clic | Sélectionner un mot |
| Triple-clic | Sélectionner la ligne |

Un champ possède le clavier pendant qu'il est édité : taper un `s` dans un nom ne déclenche pas Save.

## Taille de l'interface

| Raccourci | Action |
|---|---|
| `Ctrl` + `+` | Augmenter de 25 % |
| `Ctrl` + `-` | Diminuer de 25 % |
| `Ctrl` + `0` | Suivre la mise à l'échelle de l'écran |

Butent à 75 % et 300 %. Les touches du pavé numérique fonctionnent aussi.
