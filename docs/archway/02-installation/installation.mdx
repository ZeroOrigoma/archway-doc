# Installer le plugin

<Sheet>

**Objectif** — Mettre Archway dans votre projet Unreal.

**Durée** — 5 minutes en Blueprint, 10 à 15 minutes en C++ avec la compilation.

**Prérequis** — Unreal Engine 5.6+ et un projet UE existant.

</Sheet>

## Prérequis

| | |
|---|---|
| **Moteur** | Unreal Engine **5.6 ou supérieur** |
| **Plateforme** | **Windows 64 bits** — les trois modules d'Archway sont `Win64` uniquement |
| **Compilateur** | **Visual Studio** — uniquement pour les projets C++ |
| **Projet** | Un projet Unreal **existant**. Archway s'installe dans un projet, pas dans le moteur |

:::info Projet Blueprint ou C++ ?
**Un projet Blueprint suffit.** Archway se lance sans que vous ayez à compiler quoi que ce soit : le plugin est livré compilé. Les étapes 3 et 4 ci-dessous ne concernent que les projets C++.
:::

## 1. Récupérer le plugin et la licence

Après l'achat, vous recevez **deux e-mails distincts** :

| Expéditeur | Contenu |
|------------|---------|
| **Lemon Squeezy** | Votre facture et le **lien de téléchargement du plugin** |
| **Zero Origoma** — `licenses@mail.origoma.com` | Votre **licence**, en pièce jointe : `archway-license.zip` |

Téléchargez l'archive du plugin et décompressez-la. Vous obtenez un dossier **`ArchwayCore`**.

:::tip Gardez ces deux e-mails
L'un porte le plugin, l'autre votre licence. Si vous perdez l'un ou l'autre, faites renvoyer la licence depuis <a href="https://archway.origoma.com/reissue/">archway.origoma.com/reissue</a>.
:::

<CaptureTodo what="Les deux e-mails reçus : la facture Lemon Squeezy avec le lien du plugin, et l'e-mail de licence avec archway-license.zip" fig="Fig. 0.1" />

## 2. Placer le plugin dans votre projet

Copiez le dossier `ArchwayCore` dans le répertoire **`Plugins/`** de votre projet :

```
VotreProjet/
├── Config/
├── Content/
├── Source/
├── Plugins/
│   └── ArchwayCore/          ← coller le plugin ici
│       ├── ArchwayCore.uplugin
│       ├── Source/
│       ├── Shaders/
│       └── ...
└── VotreProjet.uproject
```

:::note Si `Plugins/` n'existe pas
Créez-le à la main, à la racine du projet — au même niveau que `Content` et le fichier `.uproject`.
:::

<CaptureTodo what="Le dossier ArchwayCore collé dans Plugins/ vu depuis l'explorateur de fichiers" fig="Fig. 0.2" />

## 3. Vérifier

Relancez le projet, puis :

1. **Edit → Plugins** : **Archway Core** apparaît, catégorie *Archway*.
2. **Window → Developer Tools → Output Log** : aucune erreur `ArchwayCore` au démarrage.

<CaptureTodo what="Archway Core listé dans le gestionnaire de plugins" fig="Fig. 0.3" />

Si le plugin ne charge pas, voyez le [dépannage](../troubleshooting/troubleshooting).

## Projets C++ uniquement

:::note Cette section ne concerne pas les projets Blueprint
Si votre projet contient du code C++, il faut régénérer la solution pour que votre IDE voie les modules d'Archway.
:::

**Régénérer les fichiers projet**

- **Clic droit sur le fichier `.uproject`** → **Generate Visual Studio project files** ;
- ou, depuis l'éditeur : **Tools → Refresh Visual Studio Project**.

**Compiler**

Au prochain lancement, Unreal détecte les modules à recompiler et propose de le faire.

- Cliquez sur **Yes**.
- Si rien ne se déclenche, compilez depuis Visual Studio en configuration **Development Editor**.

<CaptureTodo what="La fenêtre « missing modules » d'Unreal proposant de compiler" fig="Fig. 0.4" />

:::info Première compilation
Comptez plusieurs minutes : Archway embarque trois modules et des shaders de calcul.
:::

## Les trois modules

Utile pour lire l'Output Log :

| Module | Type | Rôle |
|--------|------|------|
| `ArchwayCore` | Runtime | Territoires, données, licence, save/load |
| `ArchwayRender` | Runtime | Frontières et rendu GPU |
| `ArchwayEditor` | Editor | La toolbar Archway, les imports, le bake |
