# What is Archway?

<span className="pill">Unreal Engine 5.6+</span>&nbsp;<span className="pill">Windows</span>&nbsp;<span className="pill">C++ &amp; Blueprint</span>

**Archway** transforme votre carte de provinces en un monde de stratégie UE5 jouable : frontières dessinées en shader, territoires dynamiques, map modes — conçu pour tenir 60+ fps.

<Sheet>

**En une phrase.** Vous apportez une texture de provinces et vos tables de données ; Archway construit l'appartenance territoriale, les frontières et les données runtime. Le socle de carte n'est plus votre problème.

## Un socle de carte, pas un moteur de rendu

Dans un jeu de grande stratégie, la carte n'est pas un décor : c'est la structure de données centrale. Qui possède quoi, où passent les frontières, ce que montre chaque map mode, comment tout ça se sauvegarde. C'est plusieurs mois de travail avant la première ligne de gameplay.

Archway livre cette couche :

- **Import de vos données** — texture de provinces + CSV, JSON ou DataTables. C'est la fin de la saisie manuelle.
- **Frontières dessinées en shader** — les limites entre territoires sont calculées sur GPU, pas modélisées à la main.
- **Territoires dynamiques** — conquête, fusion, division, changement de propriétaire à l'exécution.
- **Map modes stratégiques** — baronnies, comtés, duchés, royaumes, empires, pays : la même carte, plusieurs échelles de lecture.
- **Save / load** — l'état du monde se sérialise en une commande.

## Pour qui ?

- **Game designers** — prototyper des mécaniques territoriales sans écrire de code.
- **Level designers** — définir des zones d'influence, des territoires contrôlés, des régions avec leurs règles.
- **Développeurs gameplay** — une base solide pour la conquête, le contrôle de zone, la dynamique de faction.

## Ce que ce n'est pas

Archway se concentre sur la logique territoriale et son intégration dans le workflow Unreal Engine. Ce n'est pas un moteur de rendu graphique ni une bibliothèque de shaders à écrire soi-même : ces aspects sont encapsulés et transparents à l'usage.

Ce n'est pas non plus un jeu. Archway vous donne la carte et ses règles ; le gameplay reste le vôtre.
