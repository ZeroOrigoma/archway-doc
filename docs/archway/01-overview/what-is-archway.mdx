# What is Archway?

**Archway Core** est un plugin Unreal Engine 5.6+ qui ajoute un système de territoire dynamique à vos projets. Il permet de définir, manipuler et faire évoluer des zones territoriales directement dans l'éditeur, sans code.

## Un système de territoire pour Unreal Engine

Dans de nombreux jeux et simulations, les notions de territoire, de zone d'influence et de frontière sont centrales : jeux de stratégie, mondes ouverts, simulations tactiques, sandbox… Archway Core fournit une solution clé en main pour gérer ces concepts de manière performante et intuitive.

Le plugin vous permet de :

- **Définir des territoires** — créez des zones avec des formes quelconques directement dans l'éditeur UE.
- **Faire évoluer les frontières** — les territoires peuvent se dilater, se contracter, se fusionner ou se diviser en réponse à des événements gameplay.
- **Interroger l'appartenance territoriale** — savoir quel territoire contient un point, un acteur ou une zone en temps réel.
- **Visualiser les frontières** — le plugin inclut un **système de rendu de border dynamique** qui affiche les limites entre territoires de manière fluide et visuellement claire.

## Pour qui ?

Archway Core s'adresse à :

- **Les game designers** qui veulent prototyper rapidement des mécaniques territoriales sans écrire de code.
- **Les level designers** qui besoin de définir des zones d'influence, des territoires contrôlés, ou des régions avec des règles spécifiques.
- **Les développeurs gameplay** qui cherchent une base solide pour construire des systèmes de conquête, de contrôle de zone, ou de dynamique de faction.

## Ce que ce n'est pas

Archway Core se concentre sur la logique territoriale et son intégration dans le workflow Unreal Engine. Il ne s'agit pas d'un moteur de rendu graphique avancé ni d'une solution de shader personnalisé — ces aspects techniques sont encapsulés et transparents pour l'utilisateur final.
