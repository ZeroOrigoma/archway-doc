## Async Actions (Latent Nodes)

Les async actions sont des nœuds Blueprint asynchrones : ils exposent une broche `Completed` qui se déclenche quand l'opération se termine, sans bloquer le thread de jeu.

| Action | Description |
|--------|-------------|
| `UAsyncAction_ExecuteGameLoad` | Asynchronously loads game state from a save file. Returns a Completed delegate pin when loading finishes. |
| `UAsyncAction_ExecuteGameSave` | Asynchronously saves current game state to disk. Returns a Completed delegate pin when saving finishes. |
| `UAsyncAction_LoadAndMergeLandmasses` | Asynchronously loads and merges landmass geometry for multiple provinces. Provides progress updates during the multi-province load operation. |
