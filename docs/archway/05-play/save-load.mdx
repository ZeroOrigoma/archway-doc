# Sauvegarder et charger

<Sheet>

**Objectif** — Sauvegarder votre progression et la recharger dans une session ultérieure.

**Durée** — 2 minutes.

**Prérequis** — [Conquérir votre premier Duché](./conquerir) : vous contrôlez au moins un territoire.

</Sheet>

## 1. Sauvegarder

Dans le Runtime, ouvrez le **Menu**, puis cliquez sur **Save**.

<CaptureTodo
  what="Le menu Runtime avec l'entrée Save"
  fig="Fig. 8.1"
/>

:::tip Résultat attendu
L'état du monde est sérialisé : territoires conquis, appartenances, données de jeu.
:::

## 2. Charger

1. **Fermez** le Runtime, puis relancez-le avec **Play**.
2. Ouvrez le **Menu** et cliquez sur **Load**.

<CaptureTodo
  what="Le menu Runtime avec l'entrée Load"
  fig="Fig. 8.2"
/>

:::tip Résultat attendu
Le monde se recharge avec votre progression : le Duché conquis est toujours sous votre contrôle.
:::
