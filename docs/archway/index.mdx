# Documentation Archway

**Archway** transforme votre carte de provinces en un monde de stratégie UE5 jouable : frontières dessinées en shader, territoires dynamiques, map modes.

<Sheet>

**Nouveau sur Archway ?** Suivez les quatre mouvements dans l'ordre. Ils vous mènent d'un projet vide à un monde jouable et sauvegardé, avec les données de démonstration fournies.

</Sheet>

## Le parcours

<CardGrid>
  <PlateCard to="/archway/installation/installation" no="I — Installer" title="Installer">
    Poser le plugin, l'activer, vérifier que la toolbar Archway répond.
  </PlateCard>
  <PlateCard to="/archway/import/premier-monde" no="II — Importer" title="Importer">
    Créer le monde, la heightmap, les map modes, la division administrative.
  </PlateCard>
  <PlateCard to="/archway/cook/landscape-material" no="III — Cook" title="Cook">

  </PlateCard>

    Conquérir un territoire, sauvegarder, recharger.
  </PlateCard>
</CardGrid>
