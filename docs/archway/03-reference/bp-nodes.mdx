## Async Actions (Latent Nodes)

Noeuds Blueprint asynchrones avec pins de delegation :

| Classe | Description | Output Pins |
|--------|-------------|-------------|
| `UAsyncAction_ExecuteGameLoad` | Asynchronously loads game state from a save file. Returns a Completed delegate pin when loading finishes. | Completed (FOnGameLoadAsyncOutputPin) |
| `UAsyncAction_ExecuteGameSave` | Asynchronously saves current game state to disk. Returns a Completed delegate pin when saving finishes. | Completed (FOnGameSaveAsyncOutputPin) |
| `UAsyncAction_FindLabelPath` | Utilise le systeme de rendu de border dynamique pour calculer les chemins de labels de territoires. | OnComplete (FOnPathFoundAsyncOutputPin) |
| `UAsyncAction_LoadAndMergeLandmasses` | Asynchronously loads and merges landmass geometry for multiple provinces. Provides progress updates during the multi-province load operation. | OnSuccess (FOnLandmassLoadSuccess), OnProgress (FOnLandmassLoadProgress), OnFailure (FOnLandmassLoadFailure) |
